# Aplicación Laravel integrada
Consultar el README del directorio superior y `../docs/`.

Comandos desde este directorio:
- `composer install`
- `npm ci`
- `php artisan migrate`
- `php artisan certificates:admin`
- `npm run build`
- `php artisan serve`
- `php artisan queue:work --timeout=120 --tries=3`

Producción requiere PostgreSQL, una URL HTTPS definitiva, Chromium y almacenamiento persistente privado. No ejecutar `composer setup` para una instalación institucional: seguir `../docs/INSTALACION.md`.
